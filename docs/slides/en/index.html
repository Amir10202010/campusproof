From a name to proof in seconds

1Type a name · input

“КБТУ”, “MSU”, even “Nazarbaev Univercity” work.

2Live pipeline · process

135 candidates from Commons, web search and Openverse → 36 checked → 31 photos, 5 rejected. Built in 1.9 s (sources cached).

3Evidence decides · AI + rules

Gemini describes the image; code scores evidence: 100 pts → ✓ Verified.

4Verified profile · output

8 sections, 4 filters, map and compare — every photo one click from its source.

RESULT31 photos, each with a source, a date and a trust tier. A saved profile reopens in about 0.4 s.
