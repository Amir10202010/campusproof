# P2 · Проверка фото — волна 2

Ты — AI-агент роли **P2 «Проверка фото»**. Прочитай `docs/agent-playbook.md` (общие правила, цикл задачи, протокол «взять задачу») и `AGENTS.md`, дальше работай по списку ниже самостоятельно, не спрашивая подтверждения на каждом шаге.

**Твоя зона:** `lib/images/**`, `lib/sources/webSearch/**`, `lib/sources/{classifyDomain,openverse}.ts`, `lib/vision/{provider,gemini,schema,observeAll}.ts`, `lib/scoring/**`, `lib/config/**`.

**Ключи в `.env.local`** (вставляет человек): `GEMINI_API_KEY`, `SERPER_API_KEY`; для #33 — `OPENVERSE_CLIENT_ID` и `OPENVERSE_CLIENT_SECRET`. Без ключа модуль должен честно бросать ошибку, а не падать молча.

> **Это сердце продукта.** Резолвер, Commons, кеш, стрим и весь интерфейс уже готовы: как только появятся загрузка картинок и скоринг, профиль начинает показывать фото с уровнями доверия.

## Задачи по порядку

Перед каждой — протокол из регламента. Задача закрыта или назначена на другого — пропусти, бери следующую.

1. **#15 — загрузка и подготовка картинок.** `canonicalize`, `safeFetch` (только http/https, без IP-литералов и приватных сетей, ≤3 редиректа с проверкой каждого, ≤5 МБ, таймаут, `content-type: image/*`), `dhash` (64 бита + расстояние Хэмминга), `prepare` (sharp: поворот по EXIF, 640 px, JPEG, EXIF-дата и GPS), `fetchAll` (ранжирование, квоты по категориям, топ `LIMITS.VISION_MAX_IMAGES`, параллельность, фолбэк на миниатюру с `lowRes`). Тесты: картинки генерируй через sharp прямо в тесте.
2. **#17 — дедупликация и скоринг v0.** `dedupeCandidates` (точные и почти одинаковые по dHash, лучший представитель, остальные → `alsoFoundAt` и `RejectedItem`), `scoreCandidate` без визуальных сигналов (веса из `docs/architecture.md` §5.6, уровни по `TIER_THRESHOLDS`, «Проверено» только при сильном сигнале).
3. **#16 — поиск картинок (Serper).** `queryPlan` (≤ `LIMITS.WEB_SEARCH_MAX_QUERIES` запросов, шаблоны RU/EN/KZ + `site:<официальный домен>`), `serper.ts`, `gatherWebSearch`, `classifyDomain`. Ответы кешируй (`search:serper:{hash}`, TTL `LIMITS.SEARCH_CACHE_TTL_S`) — бесплатных кредитов всего 2 500.
4. **#18 — vision на бесплатном Gemini.** `schema.ts` (zod, `""` → null), `gemini.ts` (SDK `@google/genai`, `responseJsonSchema`, `mediaResolution`, `abortSignal`), `observeAll` (батчи по 12, ≤3 параллельно, повтор половиной батча, кеш `vision:{model}:{qid}:{dHash}`, 429 → vision недоступен). Модель — из `env.visionModel`.
5. **#19 — скоринг v1.** Визуальные сигналы, жёсткие отказы (другой вуз, не фото, крупный портрет), метки, причины отказа. Пороги калибруй только по разметке P3 (`eval/labels/tune`), если она уже в main.
6. **#33 — Openverse** (бесплатные CC-фото, в т.ч. Flickr).
7. **#26 — детектор повторного использования** (индекс хешей в Redis через `getRedis()`).
8. **#29 — линза «официальные vs независимые»:** интерфейс уже сделан P4, от тебя — корректный `sourceType` у всех кандидатов; закрой задачу комментарием с примерами.

Дальше — общая очередь из регламента.
