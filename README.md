# CampusProof

**Проверенный визуальный профиль университета за 30 секунд.**
Введите название университета — и получите фотографии кампуса, общежитий, аудиторий, библиотек и города, где у каждого снимка есть кликабельный источник, дата и уровень достоверности с объяснением.

## Проблема

Абитуриент выбирает вуз, который не может посетить. Официальный сайт показывает отретушированный маркетинг, а настоящие фото кампуса, общежитий, аудиторий, библиотек и города разбросаны по десяткам источников. Эти снимки дублируются, устаревают, бывают подписаны не тем вузом или вовсе непонятно откуда взялись. Поиск картинок смешивает университеты, стоки и рендеры и никак не говорит, чему можно верить.

**Для кого:** абитуриенты 16–19 лет из Казахстана и Центральной Азии, которые сравнивают местные и зарубежные вузы; их родители (важны общежития и реальность фото); консультанты по поступлению.

## Решение

CampusProof превращает название вуза в проверенный визуальный профиль: **Название → Поиск → Проверка → Категории → Профиль**. Главное правило — **лучше честное «не нашли», чем чужое фото**. У каждого снимка есть источник, дата и уровень доверия с доказательствами; слабые снимки скрыты, пустые разделы честно помечены.

| # | Требование кейса | Как закрыто | Где в коде |
|---|---|---|---|
| R1 | Поиск по названию, неоднозначные запросы | Резолвер по Wikidata: нормализация (регистр, казахские буквы, слова «университет» / «university»), ранжирование. Один явный лидер → профиль; несколько близких → список выбора с городом и страной; ничего → «Не нашли» с подсказками | `lib/resolver/*`, `components/search/PickList.tsx`, `NotFound.tsx` |
| R2 | Фото кампуса, общежитий, аудиторий, библиотек, города | Отдельный раздел на каждую область. Нет подтверждённых фото → явное пустое состояние и строка в панели «Что удалось подтвердить» | `components/profile/CategorySection.tsx`, `CoveragePanel.tsx`, `lib/config/categories.ts` |
| R3 | Автоматическая категоризация | Категорию выставляет пайплайн: подсказки из категорий и названий файлов Commons плюс наблюдение нейросети; вручную ничего не размечается | `lib/sources/commons.ts`, `lib/vision/*`, `lib/scoring/*` |
| R4 | Убрать одинаковые, похожие и нерелевантные | Перцептивный хэш (dHash) убирает одинаковые и почти одинаковые снимки; логотипы, карты, документы, стоки, рендеры и крупные портреты отсеиваются. Всё убранное видно в «Отфильтровано (N)» с причиной | `lib/images/dedup.ts`, `lib/scoring/score.ts`, `components/profile/FilteredOutTray.tsx` |
| R5 | Проверить, что фото именно этого вуза | Сигналы происхождения, геометки, текста на снимке и совпадений между источниками записываются как доказательства. Баллы и уровень («Проверено» / «Вероятно» / «Не подтверждено») считает только код; «Не подтверждено» скрыто по умолчанию | `lib/scoring/score.ts`, `components/profile/EvidenceDialog.tsx` |
| R6 | Кликабельный источник и дата | Ссылка на страницу, где нашли фото; дата с типом: снято / загружено / опубликовано / получено. Дата получения есть у каждого фото | `components/profile/PhotoCard.tsx`, `EvidenceDialog.tsx`, `lib/ui/format.ts` |
| R7 | Краткое описание по источникам | 3–5 предложений по Википедии и Wikidata, у каждого ссылка [n] на источник; без нейросети — цитата из Википедии | `lib/describe/description.ts`, `components/profile/DescriptionBlock.tsx` |
| R8 | Фильтры: общежитие, спорт, лаборатории, студенческая жизнь | Ровно четыре фильтра с этими подписями, счётчики, пустые состояния, плюс переключатель «Показывать неподтверждённые» | `components/profile/FilterBar.tsx`, `lib/ui/filters.ts` |

Сверх обязательного:
- живой таймер и этапы пайплайна со статусами источников;
- баннеры деградации и `?simulate=` для проверки сбоев;
- «Отфильтровано» с причинами;
- линза «Официальные / Независимые»;
- карта кампуса с геометками фото;
- подсказки «Как читать профиль»;
- сохранённые профили с датой создания и кнопкой «Обновить»;
- страница [`/compare`](https://campusproof.vercel.app/compare): два сохранённых профиля бок о бок по разделам и уровням. Новых проверок она не запускает.

## Как мы проверяем фотографии

Кратко для пользователей — на странице [/how-it-works](https://campusproof.vercel.app/how-it-works); спецификация — [docs/architecture.md §5.6](docs/architecture.md).

Каждый найденный кандидат проходит один и тот же путь: загрузка → дубликаты → наблюдения нейросети → очки → уровень. Особых правил под отдельные вузы нет. Очки и уровень считает только код в `lib/scoring` (`signals.ts`, `tiers.ts`), он покрыт тестами. Каждое доказательство — отдельная строка в диалоге фото, скрытых очков нет. Очки — это не вероятность.

**Доказательства и очки** (значения из `lib/scoring/signals.ts`):

| Доказательство | Очки | Сильное |
|---|---|---|
| На Wikimedia Commons отмечено, что на фото изображён этот вуз | +45 | да |
| Фото в категории вуза на Commons | +40 | да |
| Геометка не дальше 1,5 км от кампуса | +35 | да |
| Фото города с геометкой в пределах 30 км (только раздел «Город») | +35 | да |
| Фото используется в статье Википедии о вузе | +30 | да |
| Найдено на официальном сайте вуза | +30 | да |
| …но похоже на сток или рендер | +10 | нет |
| На снимке читается название этого вуза (визуальная проверка) | +30 | да |
| Страница с фото упоминает вуз | +15 | нет |
| То же фото найдено ещё на одном сайте | +15 | нет |
| Новостная статья о вузе | +10 | нет |
| Сцена соответствует описанию вуза (визуальная проверка) | +10 | нет |
| Геометка в том же городе, до 30 км от кампуса | +10 | нет |
| Сцена не похожа на описание вуза | −25 | блокирует «Проверено» |
| Рендер или иллюстрация | −40 | блокирует «Проверено» |
| Проверено только по уменьшенной копии | −10 | нет |

**Уровни** (пороги из `lib/config/limits.ts`, правило — `lib/scoring/tiers.ts`):

| Уровень | Условие |
|---|---|
| ✓ Проверено | от 60 очков, есть хотя бы одно сильное доказательство, нет рендера и сцены, которая противоречит описанию вуза |
| ◐ Вероятно | от 35 очков. Если визуальная проверка недоступна — только при сильном доказательстве; фото, которое известно лишь из веб-поиска, остаётся «Не подтверждено» |
| ? Не подтверждено | от 10 очков. Скрыто по умолчанию, открывается переключателем «Показывать неподтверждённые» |
| Отклонено | меньше 10 очков — «Слишком мало доказательств» |

**Отклоняем сразу, независимо от очков:**
- дубликаты: одинаковые и почти одинаковые снимки по перцептивному хэшу (dHash) и снимки, которые нейросеть назвала одним и тем же видом; остаётся лучший, адреса остальных — в его блоке «Также найдено на»;
- фото с фотобанков — по домену страницы или картинки, ещё до загрузки; векторные файлы, GIF и иконки — по расширению;
- геометка дальше 50 км от кампуса (кроме раздела «Город»);
- по наблюдениям нейросети: крупный портрет человека, название другого вуза на снимке, логотип или герб, карта или план, документ или скриншот, коллаж.

Всё отклонённое видно в блоке «Отфильтровано (N)» с причиной; у портретов нет превью. Снимки старше 10 лет получают пометку «возможно, устарело».

**Без визуальной проверки** (сбой Gemini, исчерпанная квота или посетитель из ЕЭЗ, Швейцарии, Великобритании) профиль всё равно строится. Уровень тогда опирается только на происхождение, геометки и совпадения источников, у каждой карточки есть пометка «Без визуальной проверки», а сверху — баннер.

## Источники данных

Только официальные API и открытые данные. Google Картинки, Instagram, Facebook, VK и 2ГИС не парсим, стоковые фотобанки не используем.

| Источник | Что берём | Лицензия и атрибуция |
|---|---|---|
| [Wikidata](https://www.wikidata.org) | Какой это вуз (резолвер), официальный сайт и домены, координаты кампуса и города, факты: год основания, число студентов, город | CC0; у каждого факта в профиле ссылка на источник |
| [Wikipedia](https://www.wikipedia.org) | Тексты для краткого описания вуза | CC BY-SA; в описании у каждого предложения сноска [n] со ссылкой на статью |
| [Wikimedia Commons](https://commons.wikimedia.org) | Фото с категориями вуза и города, отметками «на фото изображено», геометками и датами | Лицензия файла; в диалоге доказательств — лицензия, автор и ссылка на страницу файла |
| [Openverse](https://openverse.org) | Фото с открытыми лицензиями | Лицензия и автор из API, ссылка на исходную страницу |
| [Serper](https://serper.dev) | Веб-поиск изображений: официальные сайты вузов, СМИ, блоги | Лицензия обычно неизвестна — так и пишем («Не указана — права принадлежат владельцу источника»), ссылка на страницу, где найдено фото |
| [OpenStreetMap](https://www.openstreetmap.org) | Подложка карты кампуса | ODbL; атрибуция «© OpenStreetMap» на карте и под ней |

Полноразмерные изображения мы не перезаливаем: карточки и диалог показывают фото по исходной ссылке (`<img referrerPolicy="no-referrer">`), а если хост его не отдаёт — честная заглушка и ссылка на источник.

## AI-модели и API

| Модель / API | Для чего | ID модели |
|---|---|---|
| Google Gemini API, бесплатный тариф | Визуальные наблюдения по фото: тип изображения (фото, рендер, логотип, карта, документ, коллаж), похоже ли на сток, водяной знак, раздел (кампус, общежитие…), текст на снимке и называет ли он этот вуз или другой, соответствует ли сцена контексту, крупный ли это портрет, качество | `gemini-flash-lite-latest` (переменная `VISION_MODEL`) — псевдоним, который Google держит на действующей модели. Если модель перегружена или снята — запасная `gemini-flash-latest` (`VISION_MODEL_FALLBACK`) |
| Google Gemini API, бесплатный тариф | Краткое описание вуза 3–5 предложениями **только по переданным источникам**, каждое предложение со ссылкой на источник | `gemini-flash-latest` (переменная `DESCRIPTION_MODEL`) |
| Wikidata / Wikipedia / Commons API, Openverse API, Serper API | Поиск вуза, фактов, текстов и фото-кандидатов | — |
| Upstash Redis, бесплатный тариф | Кеш профилей (14 дней), ответов источников и наблюдений нейросети; ограничение частоты новых проверок | — |

**Что решает нейросеть, а что — код.** Нейросеть только описывает наблюдения в JSON; ответ проверяется схемой zod. Всё остальное — детерминированный код:
- резолвер вуза;
- сбор кандидатов и тайм-ауты источников;
- загрузка и уменьшение изображений;
- перцептивный хэш и дубликаты;
- **очки доказательств и уровень доверия** (`lib/scoring`, покрыт тестами);
- категории, пустые состояния, кеш.

Нейросеть не ставит оценку, не выбирает уровень и никогда не определяет людей на фото.

**Бесплатные квоты и защита от перерасхода:**
- до 36 изображений на визуальную проверку одного профиля (по 12 за запрос);
- `GEMINI_API_KEY` может содержать несколько ключей. Визуальная проверка переходит на следующий ключ, если текущий отклонён или его квота исчерпана (#125); описание вуза использует только первый ключ;
- до 6 запросов веб-поиска на профиль;
- при подключённом Redis — новые проверки с одного адреса за 10 минут (`FRESH_RUNS_PER_CLIENT`, по умолчанию 40) и дневной лимит новых профилей (`MAX_FRESH_PROFILES_PER_DAY`, по умолчанию 150);
- сохранённые профили открываются без ограничений.

Лимиты — в `lib/config/limits.ts` и `lib/cache/ratelimit.ts`. Для посетителей из ЕЭЗ, Швейцарии и Великобритании нейросеть не вызывается (условия бесплатного тарифа Gemini, `lib/pipeline/regions.ts`).

## Меры безопасности

- **Секреты** — только в переменных окружения Vercel и локальном `.env.local` (не в репозитории, `.env*` в `.gitignore`); все вызовы внешних API идут с сервера, ключи в браузер не попадают.
- **Недоверенный контент из источников** (подписи, названия, ссылки) выводится как текст; ссылками становятся только адреса `http(s)` — `javascript:` и `data:` отбрасываются (`lib/ui/format.ts`, `safeHttpUrl`).
- **Чужие изображения** — обычный `<img loading="lazy" referrerPolicy="no-referrer">` без перезаливки, с заглушкой при ошибке.
- **Ограничение нагрузки и расходов:** длина запроса ≤ 120 символов; при подключённом Upstash Redis — лимит новых проверок с адреса за 10 минут (`FRESH_RUNS_PER_CLIENT`, по умолчанию 40) и дневной лимит новых профилей (`MAX_FRESH_PROFILES_PER_DAY`, по умолчанию 150); сохранённые профили не ограничены.
- **Приватность:** без аккаунтов; нейросеть не определяет людей; у крупных портретов в интерфейсе никогда нет превью.
- **Тестовые данные** (фикстуры, `/dev/*`, повтор стрима) на продакшене отдают 404 (`lib/devOnly.ts`).
- **Загрузка чужих изображений (защита от SSRF)** — `lib/images/safeFetch.ts`. Сервер скачивает фото для проверки, поэтому:
  - принимаются только адреса `http(s)`;
  - отклоняются `localhost`, имена вида `*.local` и `*.internal`, частные, петлевые и link-local адреса (включая адрес метаданных облака 169.254.169.254), CGNAT и зарезервированные диапазоны IPv4 и IPv6;
  - имя хоста проверяется ещё раз после DNS-разрешения — защита от DNS rebinding;
  - редиректы обрабатываются вручную: не больше 3, каждый новый адрес проверяется заново;
  - лимиты: 5 МБ и 3 секунды на файл, только `image/*`, без SVG и GIF.

## Ограничения

- **Бесплатная квота Gemini мала.** Когда она исчерпана, профиль строится по источникам и метаданным: происхождение, геометки, совпадения между сайтами. Тогда:
  - на профиле баннер «Визуальная проверка недоступна», у карточек пометка «Без визуальной проверки»;
  - фото, которое известно только из веб-поиска, не поднимается выше «Не подтверждено»;
  - описание вуза — цитата из Википедии;
  - профиль не сохраняется в кеш.

  До полуночи 18.09 так строились все профили: Gemini не принимал ключ (#96). Если квота кончается посреди прогона, фото без наблюдения оцениваются как без визуальной проверки, а профиль не сохраняется (#123).
- **Не ищем, где ещё в интернете используется тот же снимок.** Детектора повторного использования (стоковые копии, одно фото у разных вузов, #26) нет. Мы сравниваем только кандидатов внутри одного профиля (дубликаты и «Также найдено на»), а фотобанки отсекаем по домену.
- **Не определяем, сгенерировано ли фото нейросетью.** Опираемся на происхождение: где снимок опубликован, кем и с какими метаданными.
- **Бесплатный Gemini.** Его условия не разрешают бесплатный тариф для пользователей из Европейской экономической зоны, Швейцарии и Великобритании, поэтому для посетителей оттуда визуальная проверка и описание нейросетью отключены (`lib/pipeline/regions.ts`). Профиль строится в деградированном режиме с баннером, описание — цитата из Википедии.
- **Покрытие.** Лучше всего протестировано на вузах Казахстана, Центральной Азии и крупных международных. У небольших вузов открытых фото мало — будут честно пустые разделы.
- **Даты.** У фото из веба часто нет даты съёмки: тогда показываем дату публикации или получения — всегда с типом, никогда не выдавая её за дату съёмки.
- **Геометки** есть не у всех фото; расстояния считаются по прямой.
- **Лимиты бесплатных API** (Serper, Gemini, Upstash). Если источник недоступен или исчерпан, профиль строится без него, а баннер и чип источника об этом сообщают.
- **Сохранённые профили** живут до 14 дней: изменения в источниках за это время видны только после «Обновить».
- **Люди.** Нейросеть не просят узнавать людей; крупные портреты исключаются.
- **Точность уровней не измерена.** Для неё нужна размеченная вручную выборка (#25). Ниже в «Результатах» — только то, что измерено: скорость, распределение уровней и соблюдение правил честности.
