# CampusProof

**Проверенный визуальный профиль университета за 30 секунд.**
Введите название университета — и получите фотографии кампуса, общежитий, аудиторий, библиотек и города, где у каждого снимка есть кликабельный источник, дата и уровень достоверности с объяснением.

## Архитектура и стек
Next.js 16 (App Router, TypeScript) на Vercel (fra1) · Tailwind CSS 4 + shadcn/ui · Claude API (vision) · Wikidata / Wikipedia / Wikimedia Commons · API веб-поиска изображений · Upstash Redis.
Подробно: [docs/architecture.md](docs/architecture.md).

## Запуск локально
```bash
npm install
cp .env.example .env.local   # заполните ключи
npm run dev                  # http://localhost:3000
npm run check                # typecheck + lint + тесты
```
Python-скрипты (спайки, индекс университетов, оценка качества): [scripts/python/README.md](scripts/python/README.md).
